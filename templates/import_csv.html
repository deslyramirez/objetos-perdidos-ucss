Columnas del archivo

El sistema busca la fila de títulos (puede haber un título encima, como en la plantilla). Las columnas desconocidas se ignoran y el orden no importa.

Columnas admitidas
Columna Obligatoria Valores permitidos
Objeto name Sí Nombre del objeto. Hasta 120 caracteres.
Lugar location Sí Dónde se perdió o se encontró. Hasta 120 caracteres.
Fecha del suceso event_date Sí Fecha de Excel, AAAA-MM-DD (2026-03-15) o DD/MM/AAAA (15/03/2026). No puede ser posterior a hoy.
Descripción description No Hasta 500 caracteres.
Categoría category No {% for key, label in categories.items() %}{{ label }}{{ ", " if not loop.last }}{% endfor %}. Si está vacía, el reporte queda sin categoría.
Estado status No {% for key, label in statuses.items() %}{{ label }}{{ ", " if not loop.last }}{% endfor %}. Si está vacío, se usa «Perdido».
Contacto contact No Correo o teléfono. Hasta 120 caracteres.
  • En un CSV los títulos pueden ir en español (como arriba) o en inglés (name, location…); el separador puede ser coma o punto y coma.
  • Guarde el CSV como «CSV UTF-8» para conservar tildes y eñes.
  • Las fotografías no se importan: puede agregarlas después con «Editar».
  • Los reportes importados quedan publicados a su nombre.
