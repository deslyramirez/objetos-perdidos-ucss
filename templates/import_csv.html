Formato del archivo

La primera fila debe contener los nombres de las columnas, escritos en inglés como se muestra abajo. Las columnas desconocidas se ignoran y el orden no importa.

Columnas admitidas
Columna Obligatoria Contenido Valores permitidos
name Sí Nombre del objeto Hasta 120 caracteres.
location Sí Lugar donde se perdió o se encontró Hasta 120 caracteres.
event_date Sí Fecha del suceso AAAA-MM-DD (2026-03-15) o DD/MM/AAAA (15/03/2026). No puede ser posterior a hoy.
description No Descripción Hasta 500 caracteres.
category No Categoría Puede escribir la clave o el nombre en español:
    {% for key, label in categories.items() %}
  • {{ key }} ({{ label }})
    • {% endfor %}
Si está vacía, el reporte queda sin categoría.
status No Estado del objeto Puede escribir la clave o el nombre en español:
    {% for key, label in statuses.items() %}
  • {{ key }} ({{ label }})
    • {% endfor %}
Si está vacío, se usa «Perdido».
contact No Correo o teléfono de contacto Hasta 120 caracteres.

Ejemplo con comas

name,location,event_date,description,category,status,contact
Llaves con llavero rojo,Biblioteca central,2026-03-15,Tres llaves y un llavero,keys,found,ana@universidad.edu
Mochila azul,Cafetería,15/03/2026,Contiene un cuaderno,bags,lost,

Ejemplo con punto y coma

name;location;event_date;description;category;status;contact
Calculadora científica;Aula 204;2026-03-12;Marca Casio;Electrónica;Perdido;
Paraguas negro;Entrada principal;12/03/2026;;Otros;Entregado;
  • El separador puede ser coma o punto y coma; se detecta automáticamente.
  • El archivo debe estar codificado en UTF-8 (el formato habitual al guardar como «CSV UTF-8» en Excel).
  • Máximo {{ max_rows|formato_numero }} filas y 5 MB por archivo.
  • Las filas con errores se omiten y se indican al terminar; el resto se importa.
  • Las fotografías no se importan. Todos los reportes quedan registrados a su nombre.
